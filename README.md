# ALYWAWES — студия татуировки

Учебный проект: одностраничный сайт тату-студии с личными кабинетами клиента и мастера, записью на сеанс, чатом и интерактивным созданием эскиза.

🌐 **Сайт:** [https://simahinakaterina93-coder.github.io/tattoo-studia/](https://simahinakaterina93-coder.github.io/tattoo-studia/)

---

## Возможности

- Главная страница с подводным дизайном, разделы «О студии», «Наши мастера», «Цены», «Контакты», «FAQ».
- Страница **«Мастера»** с карточками (фото, описание, кнопка «Записаться»).
- Страница **«Услуги»** с выбором услуги, мастера, свободной даты и телефона.
- **Регистрация / вход** клиента (личный кабинет).
- **Личный кабинет клиента**: загрузка фото, редактирование профиля, список записей, удаление записей, кнопка «Создать эскиз».
- **Чат с мастером** (переключение между мастерами, история переписки сохраняется).
- **Создание эскиза** в 5 шагов: стиль → место → размер → описание идеи (до 500 символов) → подбор мастера и переход в чат.
- **Вход для мастера** и **панель мастера**: список клиентов, записанных к нему, чат с клиентами, управление свободными датами.
- Плавные переходы, адаптив под мобильные экраны (до 500px).

---

## Стек

- HTML, CSS, JavaScript (без сборщиков и фреймворков).
- **localStorage** — аккаунты, записи, чаты, свободные даты, аватар.
- **Google Fonts** — Cormorant Garamond, Inter.
- **PWA-совместимость**: `manifest.webmanifest` и `sw.js` (при наличии — кэширование и установка на телефон).
- Внешний сервер не используется: все данные хранятся в браузере пользователя.
